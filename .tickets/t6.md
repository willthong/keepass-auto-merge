## What to build

A `.deb` that a Debian/Ubuntu user can install and have a working, enabled service, without
following a manual checklist.

The package installs the Python application into a private venv, installs the configuration file at
`/etc/keepass-auto-merge/config.toml` (never overwriting an existing one on upgrade), creates the
`_keepass-merge` system user, installs the systemd units, and enables the path unit and timer.
`Depends: keepassxc` so the merge engine is guaranteed present. Post-install prints the one-time
`provision` command the human still has to run.

## Acceptance criteria

- [ ] `dpkg-buildpackage` produces an installable `.deb`
- [ ] Installing enables the path unit and timer
- [ ] The config file is installed as a conffile and is not clobbered on upgrade
- [ ] The package declares its dependency on keepassxc
- [ ] Post-install instructions explain the `provision` step
- [ ] Removing the package disables the units
